# Interactive Portfolio — Otto Oyieri

A terminal-themed, interactive personal developer portfolio built as part of the
IS-PROJECT-2026 Mini-Project Git Workflow Challenge.

## 🔗 Live Site
[https://is-project-2026.github.io/interactive-portfolio-166588/](https://is-project-2026.github.io/interactive-portfolio-166588/)

## 📖 About
This is a single-page portfolio styled as a working terminal — visitors can type
commands (`help`, `about`, `projects`, `skills`, `contact`, `whoami`) directly into a live
input to navigate the site, alongside a traditional scrollable layout. It showcases:

- **COMMITed Ltd. (AgileLab1)** — group-built system, dark neon UI, Chief Data Officer role
- **Shamba Sense** — real-time ESP32 farm monitoring dashboard
- **DDWSOMS** — ML-driven sales & order intelligence proposal for Kenya Airways

## 🛠️ Technologies Used
- HTML5, CSS3 (custom properties, no framework)
- Vanilla JavaScript (DOM-driven terminal interpreter)
- Google Fonts — JetBrains Mono, Inter
- GitHub Pages (CI/CD deployment from `main`)
- Git — feature branches, Conventional Commits, PR-based workflow

## 🚀 Local Development
No build step required — clone and open `index.html` in a browser, or serve locally:

\`\`\`bash
git clone https://github.com/IS-PROJECT-2026/interactive-portfolio-166588.git
cd interactive-portfolio-166588
python -m http.server 8000
\`\`\`
